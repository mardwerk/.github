# Mardwerk brand assets

These files are derived from the selected final emblem and follow sections 3–6
of the supplied Mardwerk GPT Image 2 prompt document.

| File | Use |
| --- | --- |
| `primary-emblem.png` | Canonical full-colour emblem |
| `wordmark.svg`, `wordmark.png` | Outlined uppercase wordmark |
| `horizontal-lockup.png` | Transparent 1536×1024 horizontal lockup |
| `micro-mark.svg`, `micro-mark.png` | One-colour mark with a negative-space throat patch |
| `favicon.ico`, `favicon-*.png` | 16–64 px favicon assets |
| `app-icon.png` | Opaque 1024×1024 avatar and app-icon source |
| `brand-consistency-sheet.png` | 1536×1024 reference sheet |

## Palette

- Charcoal: `#1B1818`
- Pine-marten brown: `#673921`
- Amber: `#FDBB41`
- Warm white: `#F7F3EA`

Do not redraw the emblem from these raster derivatives. Use the canonical
emblem as the strict reference for future work, and inspect any eventual vector
redraw before trademark, print, or tiny-icon use.
