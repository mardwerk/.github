# Mardwerk organization metadata

This is GitHub's special organization repository. It contains the public
organization profile, brand assets, technical direction, and shared security
policy.

The canonical shared vocabulary lives in [CONTEXT.md](CONTEXT.md). Product repositories retain their domain-specific glossaries.

The current technical direction lives in [ROADMAP.md](ROADMAP.md), and the MIT engine/GPL MapLab/proprietary platform arrangement is recorded in [LICENSING.md](LICENSING.md). Foundation is an optional implementation workspace, not the owner of ecosystem language.
Brand sources and ready-to-use exports live in [assets/brand](assets/brand).
